# Engine selection notes

Treat `/api/schema/tts/{model}` and `/api/tts/{model}/voices` as authoritative;
installed voices can change. Runtime-verified findings are marked below.

| Edge | Fast multilingual cloud speech | Live catalog (322 voices in the guarded probe), locale/gender metadata, pitch and volume | Verified after recovery. Exact 16/16-word transcript, 7.14-second WAV, exact word-timed SRT, and no GPU. The API caches the live catalog for six hours and falls back safely when offline. |
